## 4. Execution Brief: Poin 1 (Refaktor & Penguatan Bulk Insert Excel)

Lakukan inspeksi mendalam pada file `app/Services/StudentBulkImportService.php` dan komponen terkait, lalu sajikan laporan terstruktur meliputi:

### A. Codebase Audit & Identifikasi Kelemahan Eksisting
- Identifikasi bottleneck performa pada `StudentBulkImportService.php` saat ini (evaluasi pemakaian memori `IOFactory::load()` vs chunk streaming).
- Identifikasi potensi N+1 query database pada proses validasi email dan lookup relasi (`Tutor`, `Classroom`, `Module`).
- Evaluasi penanganan error format tanggal/jadwal multi-format (`Y-m-d`, `d/m/Y`, format serial Excel).

### B. Arsitektur Solusi & Engineering Plan
Jelaskan rencana refaktorisasi secara runut:
1. **Memory Safety & Streaming Parsing:**
   - Cara konfigurasi `PhpSpreadsheet` (`IReadFilter` / `setReadDataOnly(true)`) agar mampu memproses 5.000+ baris dengan RAM konstan di bawah 64MB.
2. **Eliminasi N+1 Query & In-Memory Pre-fetching:**
   - Strategi bulk-query email existing via `whereIn` dalam 1 roundtrip.
   - Pre-caching master data Tutor dan Kelas sebelum loop pemrosesan.
3. **Database Transaction Strategy:**
   - Penanganan `DB::transaction()` untuk menjaga integritas data (All-or-Nothing vs Partial with Error Manifest).
   - Penanganan relasi beruntun: pembuatan User Siswa -> assign Classroom -> assign Tutor -> pembuatan entri `LearningSession` awal + attach `Module`.
4. **Error Reporting & User Feedback:**
   - Format response error yang dikirim ke frontend jika ada baris tidak valid (nomor baris, kolom bermasalah, dan deskripsi human-readable).

### C. Checkpoint Persetujuan (Stop Trigger)
- Akhiri respon HANYA dengan kalimat:
  **"Analisis dan konsep Poin 1 selesai. Menunggu persetujuan user sebelum menulis kode implementasi."**
- Dilarang menulis file kode implementasi sebelum mendapat konfirmasi persetujuan.
